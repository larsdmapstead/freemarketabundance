# freemarketabundance.com

Static site. Hosted on Cloudflare Workers (static assets), source on GitHub. Same pattern as Pollfinity-site.

- Site files live in `public/`
- `wrangler.toml` serves `public/` as static assets
- Push to `main` triggers a Cloudflare build and deploy once the repo is connected
- Brief: Mothership, "Free Market Abundance 2040, Vision, Principles & Website Brief, Nov 2026"
